# Пр1
## Виконала Тирканич Корнелія з групи КН-41

Практична робота з мови програмування Go, у якій реалізовано послідовне та конкурентне опитування мережевих ресурсів (URL) із порівняльним аналізом продуктивності.

##  Особливості та реалізація

Проєкт розділено на 3 рівні складності:

*   **Рівень 1. Базовий (Послідовне опитування):**
    *   Визначено структуру `Result` для збереження стану HTTP-запитів.
    *   Реалізовано інтерфейс `Checker` та кастомний `HTTPChecker` із таймаутом у 5 секунд.
    *   Обробка мережевих помилок (наприклад, `no such host`) без зупинки програми.
*   **Рівень 2. Конкурентний (Горутини та синхронізація):**
    *   Розпаралелювання запитів за допомогою горутин (`go func`).
    *   Запобігання замиканню змінної циклу шляхом передачі значення URL у параметри функції.
    *   Синхронізація виконання через `sync.WaitGroup`.
*   **Рівень 3. Просунутий (Асинхронні канали та аналіз):**
    *   Передача даних через буферизований канал `chan Result`.
    *   Використання горутини-координатора для безпечного закриття каналу `close()`.
    *   Вичитування результатів через `for res := range resultsChan` у головному потоці.
    *   Автоматичний підрахунок статистики та аналіз прискорення (Speedup).

---
## Висновок
У ході виконання практичної роботи було успішно реалізовано всі 3 рівні завдання. Отримано практичні навички побудови високоефективних мережевих утиліт мовою Go. Підтверджено перевагу асинхронного підходу із використанням горутин та каналів над послідовним виконанням при виконанні I/O-bound задач.
